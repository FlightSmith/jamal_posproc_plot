JAMAL Dashboard v25.11
Source: https://github.com/FlightSmith/jamal_posproc_plot

Keep all application files together. Python 3.11 or newer is required
(validation used Python 3.12). Run Python on the machine storing the CFD data.

Linux setup, from the extracted application folder:
  python3 -m venv .venv
  .venv/bin/python -m pip install -r requirements.txt

Start with one or more configuration names and base directories:
  .venv/bin/python jamal_dashboard_launcher_v25.py baseline "/path/to/jamal/base/dir" config_2 "/path/to/jamal/base/dir2"

Use up to five NAME PATH pairs separated by spaces, without commas. Quote paths
or names containing spaces. A single PATH uses the name Baseline. With no pairs,
Baseline uses the directory you launched Python from, not the script directory.
Relative paths are also resolved from that launching directory.

Example when already inside the CFD base folder:
  /path/to/app/.venv/bin/python /path/to/app/jamal_dashboard_launcher_v25.py

Add --no-browser on a machine where a browser should not open automatically.
Existing --host and --port options remain available. Tk is not required for
command-line paths or for typing paths in the launcher. Browse remains optional.

Windows setup, from the extracted application folder:
  py -3 -m venv .venv
  .venv\Scripts\python.exe -m pip install -r requirements.txt
Then run START_DASHBOARD.cmd, optionally with the same NAME PATH pairs.
Use python instead of py -3 if the Python launcher is unavailable.

On the launcher page:
1. Supplied names/paths appear and scan automatically. Select the desired POLARs.
2. Optional plot data controls Cp/loads distributions, Fluent convergence logs,
   and drag-rise files independently. All are on by default. Uncheck unwanted
   data to skip its reads, including cached results. Select drag-rise folders
   when using that module. ADF and required infout references always load.
3. Generate / Update dashboard. Normally leave Force full rebuild unchecked.
4. Reports and cache always use the first base folder's 03-RESULTS/DASHBOARD.
   The previous output-folder setting is ignored. Keep the generation log for
   actual paths, timings and cache information.

A new launcher process uses its command-line inputs over stale browser settings.
Refresh within the same process preserves form edits. Save/load setup includes
the three optional-data choices. Keep the terminal open while using the launcher.

Pressure values default to absolute Pa: Cp=(p_local - infout p[Pa])/qdin[Pa].
Select Legacy Cp only for already normalized inputs. Multi-element pressure and
geometry rows must match in order, with each element closing before the next.
Every pressure sample, force projection and overall reference chord is retained.

Python, dependencies and Plotly are not bundled. Charts require access to
https://cdn.plot.ly/plotly-2.35.2.min.js. Portable/offline work remains separate.
112 tests and the independent screenshot-fixture validation pass. No production
Linux timing or real network-share ACL retest was performed for this release.
